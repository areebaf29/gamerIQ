# gamerIQ - Gaming Behaviour Analytics

A small machine learning web app. Enter your gaming habits and it predicts addiction risk (High/Low), player type (Casual / Competitive / Hardcore) and an engagement level (Low / Balanced / High).

> The data is **synthetic**. About 1,900 records are generated by rules in `app.py` (fixed seed), not collected from real players. The accuracy numbers show how well each model learns those rules. They are not real-world performance.

## Pages
- **Predict** - form (name, age, gender, player category, playtime, sleep, gaming days, game type, rage level) with input checks. Shows risk from Logistic Regression and Random Forest, player type and engagement level.
- **History** - saved predictions in SQLite, with filters.
- **Models** - model comparison, feature importance and engagement-level plots.

## Models
| Task | Model |
|---|---|
| Addiction risk | Logistic Regression, Random Forest |
| Player type | Decision Tree |
| Engagement level | Fixed playtime thresholds (under 4h, 4 to 8h, over 8h). No clustering model is fitted. |

Features: playtime, sleep, gaming days, rage level, productivity drop.

## Data and results
- `generate_dataset()` draws 2,000 rows, then drops rows where playtime + sleep > 24 hours. That leaves 1,897 rows.
- The risk label comes from fixed rules on playtime, sleep, rage and productivity drop, then 6% of risk labels are flipped at random as noise. Player type and engagement level are set directly by playtime thresholds, with no noise.
- 80/20 train/test split. Models are fitted on the training split only. Test accuracy from a local run of `train_models()`:

| Model | Target | Accuracy |
|---|---|---|
| Logistic Regression | addiction risk | 89.5% |
| Random Forest | addiction risk | 91.6% |
| Decision Tree | player type | 100% (player type is a direct playtime rule) |


## Run locally
```bash
pip install flask flask-cors scikit-learn pandas numpy
python app.py
```
Open http://127.0.0.1:5000 . It trains the models on startup and creates `gamer.db` on first run. (Checked in a clean Python environment: the three pages load and the model-info endpoint responds.)

## Tech
Python, Flask, scikit-learn, pandas, NumPy, SQLite, HTML/JavaScript.

## Limitations
- Synthetic, rule-based labels, so results do not carry over to real players.
- It is a learning project, not a diagnostic tool.
